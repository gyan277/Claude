# 📢 Forum Quick Access Guide

## 🎯 Who Can Post Where?

```
┌─────────────────────────────────────────────────────┐
│                NATIONAL FORUM 🌍                     │
│           (All Ghana - Nationwide Issues)            │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ✅ Citizens can POST ⭐                            │
│  ✅ Assembly Members can POST                       │
│  ✅ Ministers can POST                              │
│                                                     │
└─────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────┐
│              DISTRICT FORUMS 🏘️                     │
│         (District-Specific Local Issues)            │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ✅ Citizens can POST (in their district)           │
│  ✅ Assembly Members can POST (in their district)   │
│  👁️ Ministers can VIEW all districts (read-only)   │
│                                                     │
└─────────────────────────────────────────────────────┘
```

---

## 📝 POSTING RULES

| Role | National Forum | District Forum |
|------|---------------|----------------|
| **Citizens** 👤 | ✅ Can post | ✅ Can post in their district |
| **Assembly Members** 🏛️ | ✅ Can post | ✅ Can post in their district |
| **Ministers** 👔 | ✅ Can post | ❌ View only |

---

## ⚠️ REQUIREMENTS

**Citizens must:**
- Be logged in
- Have verified Ghana Card
- Be 18+ years old

**Assembly/Ministers:**
- Just need to be logged in (no verification needed)

---

## 💬 WHAT EVERYONE CAN DO

Everyone (all roles) can:
- ✅ View posts
- ✅ Like posts
- ✅ Comment on posts
- ✅ Like comments
- ✅ Delete their own posts
- ✅ Delete their own comments

---

That's it! Simple role-based forum access. 🎉

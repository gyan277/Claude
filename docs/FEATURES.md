# Dodow Amanmuo - Features Guide

## 🚀 Live Features Using Groq AI

### 1. **Policy Translation** 🌍
**Location:** Any policy detail page (e.g., `/policies/1`)

**How to Use:**
1. Navigate to any policy from the Policies page
2. Look for the **Languages** button (with globe icon)
3. Click it to see the language selector
4. Choose from:
   - 🇬🇭 English (default)
   - 🇬🇭 Twi
   - 🇬🇭 Ga
   - 🇬🇭 Ewe
   - 🇬🇭 Dagbani
5. Policy bullets will be translated in real-time using Groq AI

**Powered by:** Groq `llama-3.3-70b-versatile` model

---

### 2. **Constitution Assistant** 💬
**Location:** Floating button on every page (bottom-right)

**How to Use:**
1. Look for the sparkle icon (⭐) button in the bottom-right
2. Click to open the chat interface
3. Ask questions like:
   - "What are the fundamental human rights in Ghana?"
   - "How is the president elected?"
   - "What does Article 296 say?"
   - "What are the duties of parliament?"
4. Get instant, accurate answers about Ghana's 1992 Constitution

**Powered by:** Groq `llama-3.3-70b-versatile` model

## 🎯 Quick Start

1. **Browse policies:** Go to `/policies`
2. **Translate a policy:** Click any policy → Click Languages button → Select language
3. **Ask about constitution:** Click the sparkle button → Ask a question
4. **Create account:** Click Register → Sign up → Verify with Ghana Card
5. **Vote on policies:** Login → View policy → Click Support or Oppose
6. **Join forums:** Login → Go to Forums → Post a discussion
